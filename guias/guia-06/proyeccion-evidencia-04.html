Compass / mongosh

Excelente para mostrar visualmente las bases de datos, colecciones y documentos en pestañas ("Documents", "Schema", "Indexes").

> db.parque.insertMany([...])

use & createCollection

Paso 2: Cree una colección llamada "parque"

La guía solicita expresamente el nombre exacto "parque".

En Compass: Collection Name: parque al momento de crear la base de datos.

Requerimiento 4 de la Guía

Actualizar los Datos del Primer y Último Registro

updateOne() + $set

La guía solicita expresamente: "Actualice los datos del primer y último registro". Se utiliza el método updateOne() con el operador atómico $set filtrando por la placa de cada vehículo:

1er Registro Placa: "XYZ-123"

Cambiamos el color a "Rojo Metalizado" y actualizamos el teléfono del propietario:

db.parque.updateOne(
  { placa: "XYZ-123" },
  {
    $set: {
      color: "Rojo Metalizado",
      "propietario.telefono": "3109998877"
    }
  }
);

Respuesta: { matchedCount: 1, modifiedCount: 1 }

Último Registro Placa: "MNO-345"

Actualizamos el estado a "Salida Registrada" y añadimos la hora de salida:

db.parque.updateOne(
  { placa: "MNO-345" },
  {
    $set: {
      estado: "Salida Registrada",
      horaSalida: new Date("2026-09-29T12:00:00Z"),
      totalPagar: 3500
    }
  }
);

Respuesta: { matchedCount: 1, modifiedCount: 1 }

Regla de oro: En MongoDB, siempre utilice el operador $set para actualizar campos específicos. Si omite $set en versiones anteriores, el documento entero sería reemplazado.
Requerimiento 5 de la Guía

Liste la Colección Completa

db.parque.find()

El aprendiz debe ejecutar la sentencia de lectura completa para comprobar en pantalla que existen los 5 documentos y que las modificaciones realizadas en el paso 4 se aplicaron con éxito:

// Comando mongosh:
db.parque.find();
// Con formato legible:
db.parque.find().pretty();
En Compass: basta con hacer clic en el botón "Find" o presionar Reset en la pestaña "Documents".

Qué verificar y explicar verbalmente en el video:

  • Que el 1er documento (placa XYZ-123) muestre su nuevo color "Rojo Metalizado".
  • Que el 3er documento (placa GHI-789) aún está presente en la colección (antes de su borrado).
  • Que el 5to documento (placa MNO-345) muestre su estado "Salida Registrada" y el campo totalPagar.
  • Total de documentos en este punto: 5 registros.
Paso indispensable para contrastar con el posterior borrado del paso 6.
Requerimiento 6 de la Guía

Borre el Tercer Documento de la Colección "parque"

deleteOne()

La guía solicita: "Borre el tercer documento de la colección parque". El tercer vehículo insertado corresponde a la placa "GHI-789" (Chevrolet Blanco de Andrés Silva):

Comando mongosh:
// Borrar por placa del 3er documento
db.parque.deleteOne({ placa: "GHI-789" });

También se puede eliminar por su _id exacto copiado de la consulta previa:

db.parque.deleteOne({ _id: ObjectId("...") });
Respuesta: { acknowledged: true, deletedCount: 1 }
Alternativa en MongoDB Compass:
  1. Localizar el 3er documento (vehículo Chevrolet, placa GHI-789).
  2. Hacer hover sobre la tarjeta del documento.
  3. Hacer clic sobre el icono de papelera ("Delete Document").
  4. Confirmar la acción en el cuadro emergente ("Delete").
En el video: El aprendiz debe mostrar la ejecución del comando y resaltar que la base de datos confirmó la eliminación de 1 registro (deletedCount: 1).

Requerimiento 8 de la Guía

Sentencia para Obtener Documento Según Número de Placa

findOne({ placa: "..." })

La guía solicita: "Cree la sentencia que permita obtener un documento, según el número de placa del documento." En MongoDB se utiliza un predicado de filtro directo:

// Opción 1: Obtener un solo documento exacto:
db.parque.findOne({ placa: "DEF-456" });
// Opción 2: Usando find con proyección de datos:
db.parque.find(
  { placa: "DEF-456" },
  { placa: 1, marca: 1, propietario: 1, _id: 0 }
);
En Compass: En el campo FILTER escribir: { "placa": "DEF-456" } y pulsar "Find".
Documento Único Retornado: 
{
  "_id": ObjectId("6515b8a..."),
  "placa": "DEF-456",
  "tipoVehiculo": "Motocicleta",
  "marca": "Yamaha",
  "modelo": 2023,
  "color": "Azul",
  "propietario": {
    "nombre": "Laura Martínez",
    "documento": "1083920194",
    "telefono": "3159876543"
  },
  "horaEntrada": ISODate("2026-09-29T09:15:00.000Z"),
  "estado": "Activo"
}
Explicación en video: "Al pasar la condición { placa: 'DEF-456' }, el motor de búsqueda indexa o escanea la colección y retorna exactamente el registro asociado a dicho vehículo".
