Componente Formativo 1

Arquitectura de Aplicaciones Móviles Nativas

Android (Kotlin) • iOS (Swift)

Una aplicación móvil nativa es aquella desarrollada específicamente para un sistema operativo móvil utilizando los lenguajes, herramientas de compilación y SDKs oficiales provistos por Google o Apple:

Ecosistema Android

  • Lenguaje: Kotlin (preferente) o Java.
  • UI Toolkit: Jetpack Compose (declarativo) o XML Views tradicional.
  • Entorno (IDE): Android Studio con Gradle.
  • Ejecución: Android Runtime (ART) compilando a bytecode DEX nativo.

Ecosistema iOS

  • Lenguaje: Swift (moderno) u Objective-C.
  • UI Toolkit: SwiftUI (declarativo reactivo) o UIKit con Storyboards.
  • Entorno (IDE): Xcode en macOS.
  • Ejecución: Código binario ARM compilado con LLVM directamente para el chip.

Ventajas Técnicas

  • Rendimiento Máximo: 60 a 120 FPS sin puentes de intermediación.
  • Hardware 100%: Acceso pleno a GPS, cámara, Bluetooth, sensores y biometría.
  • Patrón de Diseño: MVVM (Model-View-ViewModel) con Clean Architecture.
  • Experiencia de Usuario: Respeta al 100% las guías HIG (Apple) y Material Design (Google).

Componente Formativo 2

Herramientas para Desarrollo Móvil Híbrido y Multiplataforma

Single Codebase: Flutter • React Native • Ionic

Permiten escribir un único código base (Single Codebase) y compilar o empaquetar aplicaciones para Android, iOS y la Web simultáneamente, reduciendo drásticamente costos y tiempos de desarrollo:

Flutter (Google)

Utiliza el lenguaje Dart. No usa componentes nativos ni WebViews: dibuja cada píxel en pantalla con su propio motor gráfico acelerado por GPU (Skia / Impeller).

Rendimiento Excelente • UI Idéntica
React Native (Meta)

Utiliza JavaScript / TypeScript y la filosofía React. Se comunica mediante la nueva arquitectura JSI con widgets y vistas nativas del sistema operativo.

Look & Feel 100% Nativo • Ecosistema JS
Ionic + Capacitor

Desarrollo web puro (HTML, CSS y Angular/React/Vue) ejecutado dentro de un WebView nativo optimizado, conectándose al hardware mediante plugins de Capacitor.

Reutilización Web Total • Curva Mínima
¿Cuándo elegir Híbrido vs Nativo?: Si el software del proyecto formativo requiere desarrollo ágil para múltiples tiendas con presupuesto ajustado, las herramientas multiplataforma (Flutter / React Native) son ideales. Si requiere cómputo gráfico pesado o acceso a periféricos muy especializados, se prefiere nativo.
Componente Formativo 3

Desarrollo Web con HTML, CSS y JavaScript

El Tridente Fundamental de la Web

Todo diseño visual concebido en las herramientas de prototipado cobra vida en el navegador gracias a tres capas de tecnología complementarias e independientes:

HTML5: Estructura y Semántica

Define el esqueleto y significado de los elementos: encabezados (<header>), navegación (<nav>), formularios, tablas, imágenes y botones accesibles.

<button class="btn-primary">Pagar</button>
CSS3: Estilos y Responsividad

Controla la estética visual: colores, tipografía, márgenes, sombras, transiciones y maquetación fluida mediante Flexbox, CSS Grid y Media Queries.

display: flex; gap: 1rem; border-radius: 12px;
JavaScript ES6+: Interactividad

Otorga dinamismo: captura eventos de usuario (clics, teclado), valida formularios en tiempo real, manipula el DOM y consume APIs REST mediante fetch asíncrono.

btn.addEventListener('click', procesarPago);
Del Prototipo al Código: Figma entrega las propiedades exactas de CSS (colores, espaciados y tipografías). Dev Mode UI

Paso a Paso en Figma • Función 2

Auto Layout: El Motor de Interfaces Flexibles

Atajo: Shift + A

Auto Layout es la característica más potente de Figma: emula el comportamiento de Flexbox en CSS, permitiendo que botones, listas y tarjetas se redimensionen automáticamente según su contenido:

Parámetros Fundamentales de Auto Layout:

  • Dirección: Flujo Horizontal $ ightarrow$ o Flujo Vertical $downarrow$.
  • Gap (Espaciado entre ítems): Separación exacta en píxeles (ej. 12px entre imagen y texto).
  • Padding (Relleno interno): Márgenes superior, inferior, izquierdo y derecho dentro del contenedor.
  • Resizing: Hug contents (se ajusta al texto interno) o Fill container (se expande para ocupar todo el ancho disponible).
Ejemplo Práctico en AgroTech: Tarjeta de Producto Automática (Product Card)

Al agrupar la foto del bulto de urea, el título, el precio y el botón con Shift + A, si el nombre del producto es más largo o cambia de precio, toda la tarjeta se acomoda automáticamente sin romperse.

Equivalente CSS: display: flex; flex-direction: column; gap: 8px;
Captura para el informe: Muestra el panel lateral de propiedades con la sección de Auto Layout resaltada, indicando los valores de padding y gap configurados.
Paso a Paso en Figma • Función 3

Componentes Reutilizables y Sistema de Variantes

Atajo: Ctrl + Alt + K

Los Componentes son elementos de interfaz maestros que pueden clonarse como instancias a lo largo de todo el proyecto. Si modificas el componente principal (*Master Component*), los cambios se propagan a todas sus instancias:

1. Componente Maestro

Crea un botón o barra de navegación y presiona Ctrl + Alt + K (icono de 4 rombos morados). Se convierte en la fuente de verdad del diseño.

2. Instancias Hijas

Duplica el componente en varias pantallas (rombo hueco). Puedes cambiar el texto o ícono sin perder el estilo global ni la posición.

3. Variantes de Estado

Crea variantes para diferentes estados interactivos: botón Primary, Secondary, estado Default, Hover y Disabled.

Impacto en Desarrollo: Esta funcionalidad sienta las bases de un Design System profesional, facilitando la futura maquetación en React, Vue o HTML/CSS.
Paso a Paso en Figma • Función 4

Prototipado Interactivo: Conexión de Pantallas y Flujos

Pestaña Prototype

El prototipado interactivo convierte pantallas estáticas en una experiencia navegable simulada que el usuario puede tocar y probar en su teléfono o navegador:

1. Conexiones (Nodos)

Selecciona un botón o elemento y arrastra la flecha azul circular hacia la pantalla de destino (ej. del botón "Ingresar" hacia el Dashboard).

2. Disparadores (Triggers)

Configura el evento de activación: On click / On tap (al pulsar), While hovering (al pasar el ratón) o On drag (al deslizar).

3. Transiciones y Animación

Elige el efecto visual: Instant, Dissolve o Smart Animate (animación fluida inteligente de componentes).

Vista Previa en Vivo: Presiona el botón ▶ 'Present' para probar la app dentro de un mock de celular real. Figma Mirror App
