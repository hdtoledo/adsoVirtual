Componente Formativo 1

Arquitectura de Aplicaciones Móviles Nativas

Android (Kotlin) • iOS (Swift)

Una aplicación móvil nativa es aquella desarrollada específicamente para un sistema operativo móvil utilizando los lenguajes, herramientas de compilación y SDKs oficiales provistos por Google o Apple:

Ecosistema Android

  • Lenguaje: Kotlin (preferente) o Java.
  • UI Toolkit: Jetpack Compose (declarativo) o XML Views tradicional.
  • Entorno (IDE): Android Studio con Gradle.
  • Ejecución: Android Runtime (ART) compilando a bytecode DEX nativo.

Ecosistema iOS

  • Lenguaje: Swift (moderno) u Objective-C.
  • UI Toolkit: SwiftUI (declarativo reactivo) o UIKit con Storyboards.
  • Entorno (IDE): Xcode en macOS.
  • Ejecución: Código binario ARM compilado con LLVM directamente para el chip.

Ventajas Técnicas

  • Rendimiento Máximo: 60 a 120 FPS sin puentes de intermediación.
  • Hardware 100%: Acceso pleno a GPS, cámara, Bluetooth, sensores y biometría.
  • Patrón de Diseño: MVVM (Model-View-ViewModel) con Clean Architecture.
  • Experiencia de Usuario: Respeta al 100% las guías HIG (Apple) y Material Design (Google).

Componente Formativo 2

Herramientas para Desarrollo Móvil Híbrido y Multiplataforma

Single Codebase: Flutter • React Native • Ionic

Permiten escribir un único código base (Single Codebase) y compilar o empaquetar aplicaciones para Android, iOS y la Web simultáneamente, reduciendo drásticamente costos y tiempos de desarrollo:

Flutter (Google)

Utiliza el lenguaje Dart. No usa componentes nativos ni WebViews: dibuja cada píxel en pantalla con su propio motor gráfico acelerado por GPU (Skia / Impeller).

Rendimiento Excelente • UI Idéntica
React Native (Meta)

Utiliza JavaScript / TypeScript y la filosofía React. Se comunica mediante la nueva arquitectura JSI con widgets y vistas nativas del sistema operativo.

Look & Feel 100% Nativo • Ecosistema JS
Ionic + Capacitor

Desarrollo web puro (HTML, CSS y Angular/React/Vue) ejecutado dentro de un WebView nativo optimizado, conectándose al hardware mediante plugins de Capacitor.

Reutilización Web Total • Curva Mínima
¿Cuándo elegir Híbrido vs Nativo?: Si el software del proyecto formativo requiere desarrollo ágil para múltiples tiendas con presupuesto ajustado, las herramientas multiplataforma (Flutter / React Native) son ideales. Si requiere cómputo gráfico pesado o acceso a periféricos muy especializados, se prefiere nativo.
Componente Formativo 3

Desarrollo Web con HTML, CSS y JavaScript

El Tridente Fundamental de la Web

Todo diseño visual concebido en las herramientas de prototipado cobra vida en el navegador gracias a tres capas de tecnología complementarias e independientes:

HTML5: Estructura y Semántica

Define el esqueleto y significado de los elementos: encabezados (<header>), navegación (<nav>), formularios, tablas, imágenes y botones accesibles.

<button class="btn-primary">Pagar</button>
CSS3: Estilos y Responsividad

Controla la estética visual: colores, tipografía, márgenes, sombras, transiciones y maquetación fluida mediante Flexbox, CSS Grid y Media Queries.

display: flex; gap: 1rem; border-radius: 12px;
JavaScript ES6+: Interactividad

Otorga dinamismo: captura eventos de usuario (clics, teclado), valida formularios en tiempo real, manipula el DOM y consume APIs REST mediante fetch asíncrono.

btn.addEventListener('click', procesarPago);
Del Prototipo al Código: Figma entrega las propiedades exactas de CSS (colores, espaciados y tipografías). Dev Mode UI

Herramienta 1 • Estándar de la Industria

Figma: El Ecosistema Profesional de UI/UX figma.com

Ir a Figma Oficial

Figma es la plataforma de diseño vectorial basada en la nube más utilizada del mundo (adoptada por Google, Microsoft, Spotify y Uber). Su motor opera sobre WebAssembly (C++) y renderiza gráficos vectoriales mediante WebGL a 60 FPS, permitiendo colaboración multiusuario simultánea en tiempo real sin requerir instalación obligatoria de software de escritorio.

Pilares Técnicos para Desarrolladores ADSO:

  • Auto Layout: Análogo visual directo de CSS Flexbox (dirección de flujo, gap, padding, alineaciones, Fill Container y Hug Contents).
  • Componentes y Variantes: Paradigma POO en diseño; creación de componentes maestros e instancias con propiedades booleanas y estados (Hover, Active, Disabled).
  • Prototipado Interactivo (Smart Animate): Conexión de pantallas con transiciones automáticas que interpolan cambios de posición, escala y color entre frames.
  • Modo Desarrollador (Dev Mode): Inspección de medidas en píxeles, colores (HEX, RGBA, HSL) y generación de código CSS3, SwiftUI y Jetpack Compose.

Ficha Técnica y Criterios Formativos:

Plataformas: Web (Cualquier navegador), Windows, macOS, Linux (Web).
Licenciamiento: Plan Gratuito (Free Tier generoso con archivos y borradores ilimitados).
Exportación de Archivos: Archivo fuente nativo .fig descargable localmente y enlaces URL públicos interactivos.
Curva de Aprendizaje: Media (Intuitiva para iniciar, profunda para dominar sistemas de diseño).
¿Por qué se pide en la Guía 06?: Cumple al 100% con los requerimientos de la evidencia (permite adjuntar el archivo nativo .fig dentro del ZIP y probar Auto Layout, componentes y navegación).
Enlace Directo de Acceso: Puedes crear tu cuenta gratuita con correo SENA o personal en https://www.figma.com y comenzar a diseñar en la nube inmediatamente.
Herramienta 2 • Maquetación Ágil & No-Code

Canva: Prototipos Rápidos, Sitios Web y Mockups canva.com

Ir a Canva Oficial

Aunque comúnmente se le conoce por diseño gráfico para redes sociales, Canva se ha consolidado como una herramienta vigente de prototipado visual rápido y maquetación web. Ofrece constructores de sitios web responsivos, generador de mockups 3D de dispositivos y pizarras colaborativas (Canva Whiteboards) ideales para fases tempranas de ideación de software.

Funcionalidades para Prototipar en Software:

  • Canva Sitios Web (Websites): Permite maquetar páginas web navegables interactivas, conectando botones a páginas internas o secciones mediante anclas (scroll to anchor).
  • Smartmockups Integrados: Inserta capturas de pantallas o wireframes dentro de marcos realistas de iPhone, Samsung, MacBooks y tablets en un clic.
  • Pizarras de Ideación (Whiteboard): Diagramación colaborativa de arquitectura de información, mapas de empatía y flujos de usuario (User Flows) con notas adhesivas.
  • Publicación Web Inmediata: Permite publicar el prototipo navegable con URL gratuita (nombre.my.canva.site) para validación directa con clientes.

Ventajas y Limitaciones para Desarrollo:

✅ Ventajas: Curva de aprendizaje prácticamente nula (Drag & Drop), miles de componentes preconstruidos, ideal para aprendices en semanas iniciales o validación de ideas de negocio.
⚠️ Limitaciones Técnicas: No exporta código CSS limpio ni soporta Auto Layout técnico con propiedades flexibles. No genera archivo .fig para desarrollo profesional estructurado.
Enlace del Módulo Web: canva.com/websites/
Veredicto para el Aprendiz: Excelente para la lluvia de ideas inicial, presentaciones ejecutivas y validación de landing pages con clientes no técnicos.
Herramienta 3 • Estándares Web & Software Libre

Penpot: La Alternativa Open Source con CSS Grid penpot.app

Ir a Penpot Oficial

Penpot es la primera plataforma de diseño y prototipado 100% de código abierto (Open Source, licencia MPL 2.0) pensada para cerrar la brecha entre diseñadores y desarrolladores. Su gran innovación reside en que está construida sobre estándares web reales (SVG nativo, CSS Flexbox y CSS Grid), eliminando conceptos propietarios abstractos.

Estándares Web Reales en el Lienzo:

  • CSS Grid Nativo: Permite definir filas y columnas bidimensionales con unidades fraccionarias (1fr, 2fr), áreas de plantilla y brechas (gap) idénticas a CSS3.
  • Lienzo en SVG Puro: Todos los elementos vectoriales se almacenan como código SVG nativo, lo que garantiza fidelidad perfecta al llevar el diseño al frontend web.
  • Inspección para Código Frontend: Genera código HTML semántico y reglas CSS directamente utilizables en hojas de estilos.
  • Prototipado Interactivo: Enlaces entre pantallas, transiciones visuales e interacciones funcionales.

Soberanía y Filosofía Open Source:

Nube Gratuita Ilimitada: Proyectos, archivos y colaboradores ilimitados sin planes de pago restrictivos.
Autoalojamiento (Self-Hosted): Se puede instalar en la infraestructura local del SENA o de una empresa mediante contenedores Docker.
Repositorio Público: Código auditable en GitHub (github.com/penpot/penpot).
Curva de Aprendizaje: Similar a Figma; el aprendiz familiarizado con CSS aprende más rápido.
¿Cuándo usarla en ADSO?: Ideal para aprendices que defienden el software libre, proyectos que exijan soberanía de datos o prácticas donde se quiera aprender CSS Grid mientras se diseña.
Acceso Directo: Regístrate gratis en https://penpot.app y experimenta el diseño basado en estándares web reales.
Herramienta 4 • De Diseño a Producción

Framer: Microinteracciones Avanzadas y Código Real framer.com

Ir a Framer Oficial

Framer es la herramienta de diseño y prototipado interactivo que une el diseño visual con la programación web en producción. Construida sobre el ecosistema de React y Framer Motion, no genera maquetas estáticas con cables simples, sino prototipos reactivos de alta fidelidad con animaciones físicas reales listos para publicarse como sitios web en vivo.

Ventajas Técnicas y Microinteracciones:

  • Motor de Animación Framer Motion: Transiciones basadas en físicas de resortes (spring physics), animaciones ligadas al scroll (parallax) y efectos 3D.
  • Componentes Reactivos Dinámicos: Formularios funcionales que capturan datos reales, interruptores con lógica y estados interactivos complejos.
  • Breakpoints Responsivos Simultáneos: Diseña al mismo tiempo para Desktop, Tablet y Móvil viendo la adaptación en tiempo real.
  • Publicación a Producción con 1 Clic: Aloja el prototipo como un sitio web ultrarrápido con CDN mundial, SSL y optimización SEO.

Perfil Técnico y Consideraciones:

Nivel de Fidelidad: Máxima (Indistinguible de una aplicación terminada en producción).
Licencia: Freemium (Diseño gratuito y publicación gratuita en subdominio .framer.app).
Curva de Aprendizaje: Media-Alta (Requiere entender conceptos de React, breakpoints y layouts flexibles).
Colaboración: Nube multiusuario en tiempo real.
¿Cuándo usarla en ADSO?: Cuando el software a desarrollar sea un portal interactivo o app web donde la experiencia estética, las microinteracciones y el dinamismo visual sean factores diferenciadores.
Sitio Oficial: Explora proyectos y plantillas interactivas en https://www.framer.com.
